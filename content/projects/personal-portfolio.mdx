A personal portfolio site designed and built from the ground up as a living, evolving home base on the internet. More than a resume page — it's a digital living room where work, writing, speaking, and ongoing projects all live together in one place.

## Why Build It

Most portfolio sites are static snapshots. This one is designed to grow with me — a single source of truth for everything I'm working on, thinking about, and shipping. Built in public, updated continuously, and structured so that adding a new project or piece of writing is as simple as dropping in a markdown file.

## Stack

- **Next.js** — React framework with App Router and static generation
- **Velite** — type-safe content layer for MDX and YAML
- **MDX** — rich content with embedded components
- **Tailwind CSS** — utility-first styling
- **Vercel** — deployment and hosting

## Design Principles

- **Content-first** — the structure serves the work, not the other way around
- **Low-friction updates** — new content goes live with a single file and a push
- **Iterative by default** — the site ships incrementally rather than waiting for perfection
