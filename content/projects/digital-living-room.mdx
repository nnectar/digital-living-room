## The Concept

Most personal websites split into two: a sterile portfolio for work, and a blog for everything else. This site refuses that split. It's a single space where the subject matter determines the mood — projects feel sharper and code-forward, writing feels warm and typographic, photos feel gallery-like.

## Technical Decisions

- **Next.js App Router** for file-based routing and server components
- **Tailwind CSS v4** with a custom design token system using OKLCH colors
- **Velite** for type-safe content management (MDX + YAML + JSON)
- **Subject-based moods** via CSS custom properties scoped with `data-mood` attributes

## What I Learned

Building a design system from scratch taught me more about CSS custom properties, color spaces, and intentional typography than any tutorial could. The mood system — where each section gets its own accent color and card behavior — was the most rewarding part to build.
